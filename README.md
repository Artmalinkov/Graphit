# Graphite

**Проект для создания и отображения интерактивного графа персональных социальных связей. Основа -
хранилище заметок .md в Obsidian**
---

## 🧠 Почему Graphite?
В современном мире ваш самый ценный ресурс — это люди и связи между ними.
Технологии меняются. Инструменты устаревают. Знания требуют обновления. 
Но ваши социальные связи — это единственный актив, 
который со временем только дорожает. Каждый человек в вашем окружении — это:
- Доступ к знаниям и опыту, которых нет в интернете
- Точка входа в новые проекты, рынки и возможности
- Поддержка в сложных ситуациях
- Вдохновение для личного и профессионального роста

Исследования показывают, что качество социальных связей — один из главных факторов 
долголетия, счастья и успеха. Сильные связи дают опору. 
Слабые связи приносят новые возможности.

Представьте, что вы:
- Ищете эксперта в новом направлении — граф показывает, кто из ваших знакомых 
    может быть связан с этой сферой
- Хотите расширить круг общения — видите, какие кластеры людей ещё не задействованы
- Планируете проект — мгновенно находите всех, кто может быть полезен
- Хотите не потерять контакт с важными людьми — граф напоминает о связях, 
   которые требуют внимания

## ✨ Основные возможности

- **Парсинг заметок:** извлекает имена, контакты, даты, увлечения и связи из `.md` файлов Obsidian.
- **Хранение в PostgreSQL:** все данные структурированы и готовы к сложным запросам.
- **Интерактивный граф:** визуализация связей с возможностью масштабирования, поиска и фильтрации.
- **Гибкая архитектура:** легко добавить новые источники данных или типы связей.
- **GUI на PySide6:** удобный интерфейс для работы с графом (в планах).

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Artmalinkov/Graphit.git
cd Graphite
```
### 2. Создание виртуального окружения
```bash
python -m venv venv
venv\Scripts\activate     # Windows
source venv/bin/activate  # Linux/Mac
```
### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Скопируйте .env.example в .env и укажите свои параметры:
```txt
DB_HOST=localhost
DB_PORT=5432
DB_NAME=graphite_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
OBSIDIAN_PATH=D:/путь/к/вашему/хранилищу
```

### 5. Создание базы данных
```sql
CREATE DATABASE graphite_db;
```
### 6. Запуск
python scripts/run_parser.py   # Парсинг заметок
python scripts/run_loader.py   # Загрузка в БД
python scripts/run_visualizer.py  # Построение графа
