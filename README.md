# Graphite

**Проект для создания и отображения интерактивного графа персональных социальных связей. Основа -
хранилище заметок .md в Obsidian**

## 📖 О проекте

**Разрозненные заметки о людях сложно анализировать. Graphite структурирует их и показывает связи.**

- **Для кого он?**
  - Личное использование
  - Менеджеры по работе с клиентами
  - Исследователи социальных сетей

- **Какую ценность дает?**
  - Визуализация связей между людьми и компаниями
  - Быстрый поиск нужного контакта
  - Аналитика: кто с кем связан, кластеры общения, слабые связи

---
## ✨ Основные возможности

- **Парсинг заметок:** извлекает имена, контакты, даты, увлечения и связи из `.md` файлов Obsidian.
- **Хранение в PostgreSQL:** все данные структурированы и готовы к сложным запросам.
- **Интерактивный граф:** визуализация связей с возможностью масштабирования, поиска и фильтрации.
- **Гибкая архитектура:** легко добавить новые источники данных или типы связей.
- **GUI на PySide6:** удобный интерфейс для работы с графом (в планах).

Obsidian (.md) → Парсер → JSON → PostgreSQL → NetworkX → Pyvis/PySide6 → Интерактивный граф

## 🚀 Быстрый старт

### 1. Клонирование репозитория
git clone <ссылка_на_репозиторий>
cd Graphite
### 2. Создание виртуального окружения
python -m venv venv
venv\Scripts\activate     # Windows
source venv/bin/activate  # Linux/Mac
### 3. Установка зависимостей
pip install -r requirements.txt
### 4. Настройка переменных окружения
Скопируйте .env.example в .env и укажите свои параметры:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=graphite_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
OBSIDIAN_PATH=D:/путь/к/вашему/хранилищу
### 5. Создание базы данных
CREATE DATABASE graphite_db;
### 6. Запуск
python scripts/run_parser.py   # Парсинг заметок
python scripts/run_loader.py   # Загрузка в БД
python scripts/run_visualizer.py  # Построение графа
